After committing:
1. Open GitHub -> Actions.
2. Select "SafeContext Privacy Gate Demo".
3. Click "Run workflow".
4. Select main and run it.

The demo intentionally uses synthetic data only.
The workflow proves:
- raw input is BLOCKED
- inspect reports sensitive categories
- protect pseudonymizes identifiers and redacts secrets
- protected content is SAFE TO SHARE
- a simulated LLM response can be restored locally
- secrets are neither restored nor stored in the mapping
